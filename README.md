# I-Tennis Mobile（確認用プレビュー）

テニスの予定を管理するスマホ向けアプリ「I-Tennis Mobile」の **確認用公開版**（Ver.0.3.0-R1）です。
ホーム画面に追加して、アプリのように使えます（PWA）。

> これは動作確認のための**プレビュー**です。正式版ではありません。

## 使い方（iPhone）

1. Safariでこのページを開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「I-Tennis」アイコンから起動

Androidは、Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。

## データについて

予定データは、お使いの端末のブラウザ内（localStorage）にだけ保存されます。サーバーへは送信されません。
一度オンラインで開くと、オフラインでも画面が起動します。
